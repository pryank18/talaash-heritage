1776: waste land

Halhed’s Code of Gentoo Laws: “Land Waste for Five Years, or whatever longer Time it may happen, such Land is called Jungle.”

Only later did English use it for dense forest and tangled growth.

Sources: N. B. Halhed, A Code of Gentoo Laws (London, 1776), p. 190; Merriam-Webster, jungle. More: talaash-heritage.pages.dev/india-s-linguistic-heritage
