# Interactive 3D models and their Jaisa Tha episodes

Evidence sheets for models first built as Claude Design canvases (cloud tasks cannot open canvases, so the evidence lives here). Each model becomes:
1. a free interactive page on the site, `site/3d-<slug>.html` (three.js, orbit and walk, evidence tag on every element, "Reconstruction" label, Talaash logo, links to the programme in the ledger's `sells` and to both handles), and
2. a Jaisa Tha reel rendered from the same scene (see render/jaisatha/README.md).

Ledger entries: content/universe.json (web-3d-kandariya, web-3d-bhaja, tl-jaisa-tha-04-kandariya, tl-jaisa-tha-06-bhaja). Re-verify every figure with the three checks before publishing; a figure that rests only on Wikipedia must be confirmed from the book it cites or dropped.

- kandariya-sources.md — Kandariya Mahadeva, Khajuraho (canvas aa5f80ed-5676-496a-aaee-353ea79aee60)
- bhaja-sources.md — Bhaja Cave 12 chaitya (canvas 478bfafe-eaef-4987-bd7d-5d54414d37e2)
- heliodorus-sources.md: Heliodorus pillar, Vidisha (linguistics); sources chosen, figures not yet extracted
- toda-dwelling-sources.md: Toda dwelling hut, Nilgiris (anthropology); sources chosen, figures not yet extracted
- bhimbetka-shelter-sources.md: a painted shelter at Bhimbetka (arts); sources chosen, figures not yet extracted

Built pages: site/3d-kandariya-mahadeva.html and site/3d-bhaja-chaitya.html (content/models3d.json, tools/build_3d.py). The figures on those pages are the ones that passed the three checks on 11 Nov 2026; the sheets above them list what was dropped and why.
