# What the Text Says: reel tooling (made 14 Nov 2026 for #01)
Cloud only; nothing needs a laptop.

1. Voice (English clone, lecture studio method: F5-TTS v1 Base from Pryank's reference voice). Reference: Drive "archaeologywala – voice reference 30s (Pryank).mp3" (1yVI11bYIze9q-oKyQ6mtC_iyH7DBBxcd; the Drive download tool saves it to a local file). Prompt clip: `ffmpeg -ss 6.6 -t 6.1 -i ref.wav -af "afade=t=in:d=0.05,afade=t=out:st=5.95:d=0.15,apad=pad_dur=0.7" ref6.wav`, reference text "And three different concepts of maths: algebra, geometry and arithmetic." Do not use the first 10 s of the reference: its transcript is unclear and the model then leaks "maths" into every line. Install from PyPI (the pytorch.org index is blocked): `pip install --break-system-packages torch torchaudio f5-tts faster-whisper speechbrain`. One WAV per narration line, nfe 24; about 2.5–4 min a line on 2 CPUs. Per-line spellings and seeds for #01 are in render/wtts/01-zero/script.md.
2. Likeness check (SpeechBrain ECAPA, speechbrain/spkrec-ecapa-voxceleb) of the finished narration against the held-out 13–29 s of the reference. Calibration on 14 Nov: reference vs itself 0.59; two unrelated voices 0.03 and 0.09; pass mark 0.25. #01 scored 0.358.
3. Transcript check: faster-whisper medium per line and on the finished file; diff with script.md. Whisper mishears rare words (ṣifr, cifra, Apte) as common ones; reword a line if a key word is heard as a different real word (#01: "ṣifr" heard as "cipher", so the line says "the Arabic word ṣifr").
4. Timeline and audio: join the line WAVs with 0.24 s gaps (lead 0.35 s, tail 1.4 s); captions split into chunks of at most about 80 characters, timed by character share of each line; timeline.json holds line spans and caption chunks (render/wtts/01-zero/timeline.json).
5. Frames: render/wtts/01-zero/scene.html exposes build() and render(t); load it in headless Chromium (Playwright, 1080×1920, device scale 1), set window.TL to the timeline, call build(), then render(i/30) and screenshot each frame. Fonts: `npm pack @fontsource/noto-sans @fontsource/tiro-devanagari-sanskrit @fontsource/noto-naskh-arabic`, unpacked into ../fonts/ beside the scene; logo site/assets/img/logo-badge.png copied next to it.
6. Encode: loudnorm I=-14; ffmpeg two-pass libx264 520 kbit/s, yuv420p, High profile, + AAC 96k mono, +faststart. #01: 58.2 s, 4.65 MB.
7. Checks: logo region identical on every frame; contact sheet of one frame a second; size ≤ 4.8 MB; 45–60 s.
