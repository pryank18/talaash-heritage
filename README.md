# Talaash Heritage store

The website lives in `site/`. Cloudflare Pages publishes that folder.

Configuration: `site/assets/js/config.js` (public values only, never the Supabase service_role key).

Live site: https://talaash-heritage.pages.dev (auto-deploys from main via Cloudflare Pages).

Every push to `main` goes live automatically.

Programmes run on request are listed in `site/data/catalogue.json`, which is generated by `python3 tools/build_catalogue.py site/data/catalogue.json`. Edit the programme text, the what-it-covers lines and the practical details in that script, then run it. The same file hides or relabels database listings that are not on sale yet. Dated, paid events are added in the admin page.
